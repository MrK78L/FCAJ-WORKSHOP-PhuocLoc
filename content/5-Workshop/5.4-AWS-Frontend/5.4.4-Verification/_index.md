# Verify the AWS setup

- Test Cognito registration, email confirmation, sign-in, and authorization.
- Verify public, authenticated, and administrator API behavior.
- Confirm office, rental request, appointment, and contract records in DynamoDB.
- Test presigned uploads and image processing between S3 buckets.
- Inspect Lambda logs, CloudWatch metrics and alarms, SNS, and the EventBridge schedule.
- For failures, inspect CloudFormation events, CORS, Lambda logs, IAM Roles, and frontend environment variables.
